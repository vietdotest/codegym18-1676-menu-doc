# Menu dropdown dọc

Menu dọc dùng ul/li lồng nhau, relative/absolute, top:0 left:160px và visibility. Hover và focus-within mở menu con, hỗ trợ bàn phím.

## Chạy
Mở index.html trong trình duyệt.

## Đề bài
https://internship.codegym.vn/learning/18/activity/1676

## Kiểm tra
375, 768, 1440 px không tràn ngang. Menu con ẩn mặc định, mở khi dùng Tab. Header/sticky giữ top=0 sau khi cuộn bằng liên kết nội trang.
